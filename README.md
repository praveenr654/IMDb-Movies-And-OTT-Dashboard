# 🎬 IMDb Movies & OTT Dashboards

An interactive **Power BI** analytics dashboard analyzing movie ratings, genres, box office performance, and OTT platform distribution based on IMDb datasets.

---

## 📌 Features

* **Overview & Key Metrics:** Total movies, average IMDb rating, total votes, and top-performing genres.
* **OTT Platform Analysis:** Insights into content distribution across Netflix, Amazon Prime, Disney+, and other streaming services.
* **Genre & Trend Breakdown:** Historical trends in movie releases, runtime analysis, and rating dynamics over time.
* **Top Hits & Cast Analytics:** Highlighting top-rated movies, directors, and actors.
* **Interactive Filters:** Filter by year, content rating, country, genre, and streaming platform.

---

## 🛠️ Built With

* **Power BI Desktop** — Data modeling, DAX measures, and visual reporting.
* **Power Query** — Data cleaning, transformations, and ETL process.
* **IMDb Dataset** — Movies, ratings, and streaming availability data.
